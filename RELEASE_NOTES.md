# DarkSunRE 1.13.0

## Редактор WIND/BUTN

- Добавлен редактор окон `WIND`: пункты, их `Id`, исходные и новые координаты `X/Y`.
- Добавлен редактор кнопок `BUTN`: размеры, смещения иконки и текста, `IconId`, hotkey и текст.
- Оригинальные значения всегда читаются из исходного GFF, редактируемые — из нового/сгенерированного файла.
- Изменения сохраняются в `ModifiedData`; при генерации запись попадает только в изменённый GFF.
- JSON для WIND/BUTN сохраняется в `<JsonFolderPath>\<GFF>\<TAG>-<номер>.json` и содержит исходные и новые значения.

## Размер иконок и кнопок

- Для статических изображений (`ICON`, `BMP`, `TILE`, `WALL`, `PORT`, `CBMP`) разрешён импорт PNG с новыми размерами.
- При изменении размера `ICON` автоматически обновляются соответствующие `BUTN.Width/Height`.
- Позиция пункта `WIND` сдвигается на половину изменения размера, чтобы подпись оставалась по центру.
- Прозрачность кадров сохраняется: экспорт пишет `tRNS`, импорт восстанавливает alpha-маску и не закрашивает прозрачный фон.

## Автоматический импорт ресурсов

- При **Generate new file** сканируются папки с именем GFF-файла:
  - `<ModifiedGamePath>\Resource`
  - `<JsonFolderPath>\Resource`
  - `<OriginalGamePath>\Resource`
  - аналогично для `Cine`, `GPLDATA` и других файлов.
- Поддерживаются:
  - `TAG-N.png` — одиночный кадр;
  - `TAG-N_000.png`, `TAG-N_001.png` — последовательность кадров;
  - `TAG-N.txt` — текст;
  - `TAG-N.json` — WIND/BUTN.
- Ошибки импорта показываются в статусе и не блокируют генерацию остальных ресурсов.

## Шрифты

- При генерации GFF шрифт `FONT` всегда пересобирается с учётом PNG из `Glyphs\Overrides`.
- Это работает, даже если редактор шрифта не открывался.
- Изменённые глифы попадают в сгенерированный ресурсный файл.

## Прочее

- Сохранены исправления предыдущей версии: последние проекты в меню File, меню View для возврата панели Files, импорт/экспорт графики, раздельные оригинальные и изменяемые колонки Text/NAME.
- Сборка: 70 тестов проходят.

## Установка

Архив `DarkSunRE-1.13.0-win-x64.zip` содержит self-contained сборку для Windows x64. .NET отдельно устанавливать не требуется.
